# Project Horizon

**Designing Homes That Adapt, Endure and Thrive for the Next 100 Years**

A publishing project for a full-colour handbook on climate-responsive, remodelable, steel-framed residential design.

## Working Author
K Ofuafor

## Purpose
Project Horizon explores how to design homes as long-life platforms: durable structure, high-performance envelope, replaceable services, adaptable interiors, and future-ready infrastructure.
